# Import a rendered web page

Use for an explicitly selected page or section the user wants recreated in Figma. This is a bounded visual snapshot, not HTML execution in the plugin, a responsive implementation or an exact browser renderer. Keep the local MCP architecture. Browser access is provided by the agent's available browser tool; this package does not install a browser, download a URL, reuse browser profiles or handle login credentials.

## Capture

1. Open the intended page using an available authorized browser workflow. Inspect the visible page, choose the viewport and section, and wait for its intended content/fonts/images to load. Do not crawl links or change form state. If browser access or required login is unavailable, ask for the missing access or a previously captured snapshot; do not invent DOM data.
2. Read this skill's `scripts/web-capture.js`. It is a self-contained function expression. Run the reviewed function with `{selector: "...", maxNodes: 200}` in the selected page using a browser API that supports DOM evaluation. For Playwright, `page.evaluate(captureFunction, options)` is the pattern; adapt to the actual tool's supported API and permissions. The function reads the rendered DOM and computed styles; it uses detached canvas elements to copy readable image pixels. Do not inject remote scripts or use a service that uploads the page elsewhere. If the tool cannot perform this capture, report that limitation instead of bypassing its constraints.
3. Capture a screenshot of the same section/state with the browser tool. Keep it and the JSON only in an appropriate temporary directory or the user's chosen project. The collector does not return URLs, links, cookies, storage, script bodies, input values, textarea/select contents, editable-field text or CSS-masked text. Ordinary visible text and accessible images are still project data; never save them in the integration/skill release.
4. Inspect `coverage` and warnings. `coverage.complete` describes the bounded light-DOM traversal, not visual fidelity: unsupported rendering still appears in warnings. Capture smaller sections after node/depth/traversal/byte limits. Do not silently import a cut-off page as complete. The default is 200 nodes; the collector rejects a section above 20000 px per side, skips nesting beyond 40 and stops after 10000 visited nodes. Re-read after page changes; snapshots are not atomic on animated pages.

The collector does not fetch images or bypass CORS. Loaded readable images are embedded as PNGs; unavailable, oversized or cross-origin-blocked images remain explicit placeholders. Per-image bounds: 4096 px per side, 2 MiB base64. Aggregate limits: 40 images, 16 megapixels and 3 MiB base64 in the collector; the entire snapshot is limited to 4 MiB. Text is limited to 2000 UTF-16 units per fragment, with explicit truncation warnings. For important missing artwork use an authorized local asset and the existing import_image/import_svg workflow separately.

## Preview and apply

Prefer saving the JSON to a local file so large PNG strings need not pass through the conversation. Use `import_web_snapshot({filePath: "/absolute/project/capture.json", parentId, x, y})`. It reads only within the existing import `allowedRoots` grant; follow [asset-access.md](asset-access.md) if the user-selected folder needs a grant. Small snapshots can use `snapshot` inline instead. Exactly one source is required. The tool accepts no URL and does not execute page scripts.

The destination must be an existing page, section or frame without Auto Layout. This creates one root frame; it creates no page and changes no style-guide tokens. Default `dryRun: true` validates structure/image bounds and chooses available fonts without loading them or creating layers. Show the source scope, warning summary and placement. Apply within the already authorized import task using identical source/destination, `dryRun: false`, the returned `revision` and the usual operation ID. A changed file, font selection, placement, destination ID or plugin session requires a new preview. Normal operation recovery applies to timeouts; do not blindly re-import with a new ID.

Text remains editable. Simple non-wrapping flex containers can become fixed-size Auto Layout; the importer retains it only when Figma child geometry matches captured positions/sizes within 1 px. Otherwise it restores coordinates and reports the fallback. Other layouts use fixed coordinates. Fonts require Figma availability; unavailable requested family/weight/style falls back to Inter Regular with a warning. If neither font is available, the import fails before creating layers. No webfont is downloaded or installed.

Fresh captures mark text as single-line or wrapped. Single-line runs use Figma's natural text width to avoid unintended wrapping from small browser/font metric differences; significant size adjustments are reported as `text_metrics_adjusted`. Wrapped runs and older snapshots without this metadata retain their captured boxes. Re-capture with the current collector when an old snapshot wraps short labels incorrectly. This does not guarantee identical typography; inspect the exported result.

Warnings cover approximate wrapped text, unsupported color formats, borders, gradients/background images, shadows, pseudo-elements, transforms, masks, stacking, embedded content, shadow DOM and frozen animation/scroll state. SVG/canvas/video/iframes and form controls are not reconstructed; their boxes and warnings remain. Source opacity/clipping, uniform solid borders and corner radii are supported. A successful import is not evidence of matching pixels, interactions or accessibility.

On a construction failure, the importer attempts to remove only its new layers. Incomplete cleanup names remaining IDs; inspect before further writes. Figma may retain unreferenced imported image bytes. Existing layers are not rewritten, and no complete document transaction is promised.

## Compare

Export the returned `rootId` with `export_node` and compare it visually with the captured browser screenshot at the same dimensions. Check text wrapping/baselines, fonts, image crops, spacing, clipping and stacking. Explain visible deviations and unresolved warnings; fix only within the requested scope. If live Figma verification was deferred, say so and keep this step pending. Mock tests cannot prove Figma rendering. Keep screenshots and comparison notes out of integration packages.

DOM APIs: [computed styles](https://developer.mozilla.org/en-US/docs/Web/API/Window/getComputedStyle), [text ranges](https://developer.mozilla.org/en-US/docs/Web/API/Range/getClientRects), [image CORS limits](https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/CORS_enabled_image).

Boxless wrappers (`display: contents` or zero-size containers with visible overflow) are flattened into the nearest captured parent; visible descendants keep their captured coordinates. Hidden ancestors with boxes retain a transparent container for explicitly visible descendants. Group opacity after flattening is approximate and warned. Zero-size clipping is omitted with `coverage.complete: false` and `boxless_clipping_omitted`; choose a supported section or inspect the browser reference instead of treating that result as complete.
