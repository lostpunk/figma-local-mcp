# История изменений

## 0.7.24

- При несовпадении версий плагина и MCP предупреждение остаётся в компактном индикаторе после прочтения. Пульсация прекращается; обычный статус возвращается после устранения несовпадения.
- Ошибка изменения размера окна сохраняет прежний режим и не записывает неудачную настройку. UI раскрывает подробности и отмечает уведомление прочитанным только после подтверждения плагина; ошибки окна включаются в локальный журнал и отчёт поддержки.
- Снимки потомков Auto Layout используют компактные индексы полей вместо повторения их названий. Все прежние проверки значений, отсутствующих полей и вложенности сохранены; лимиты памяти не увеличены.

## 0.7.23

- Компактное окно со статусом, раскрытием подробностей и сохранением режима между запусками. Сворачивание не отключает MCP и доступно во время операций.
- Кнопки перемещения к левому и правому краю рабочей области. Это размещение отдельного окна, а не встраивание в панели редактора.
- Цвет, значок и текст показывают подключение, выполнение операции и важные события. Ошибки сохраняют приоритет до просмотра; короткая пульсация учитывает системную настройку уменьшения движения. Окно не раскрывается автоматически.

## 0.7.22

- Привязки проверяются после каждой записи: ручное изменение цвета, обводки или стиля во время асинхронного назначения текстового стиля не становится основанием для отката и не заменяется старым значением. Непроверенное состояние слоя сохраняется с явным сообщением о неполном откате; независимые неизменённые слои восстанавливаются.
- Сравнение текстовых стилей и снимки состояния учитывают `textWrapStyle`: разные режимы переноса строк больше не считаются точным совпадением.
- Добавлены проверки конфликтов во время назначения стиля, сохранения ручных правок, успешного применения и восстановления привязок.

## 0.7.21

- Предпросмотр роста фиксированных текстовых рамок с проверкой соседей; текст и шрифты сохраняются.
- Предпросмотр отступов, промежутков и размеров фиксированных Auto Layout фреймов с расчётом позиций детей и проверкой результата. Неоднозначные структуры возвращают ограничение.
- Панель итогов аудита в плагине, причины пропуска правок и переход к проблемному слою. Применение отделено от подтверждения повторным аудитом.
- Явные правила дизайн-системы проекта: переменные цвета, текстовые стили, компоненты и исключения. Предпросмотр однозначных привязок с сохранением внешнего вида; замены компонентов и неподходящей типографики остаются отдельной задачей.
- Правила устойчивой структуры макетов в скилле и устранение устаревших указаний диагностики.

## 0.7.20

- Исправления выбранных замечаний `OUTSIDE_PARENT`: предложение перемещения простой фигуры внутрь фрейма через `preview_audit_fixes`, выбор правок и повторный аудит. Неоднозначные случаи возвращаются с объяснением.
- Зашифрованная локальная история операций, чтение результатов после перезапуска и `list_operations` для поиска прежних ID. Неопределённые операции не повторяются; объём и срок хранения ограничены.
- Проверки обновления форматов v1/v2, сохранения локального состояния, отката при ошибке и восстановления файлов той же версии. Отдельная команда проверяет обновление из распакованного старого релиза в изолированной установке.

## 0.7.19

- Предпросмотр свойств существующих слоёв через `preview_changes` и выбор отдельных изменений через `apply_changes`, без создания копий или страниц.
- Одноразовые планы с пятиминутным сроком действия, проверкой свойств и контекста выбранных слоёв перед применением; ручные изменения не перезаписываются при обнаружении конфликта.
- Проверка записанных значений, попытка восстановления затронутых слоёв при ошибке и явное сообщение о неполном откате. Повторное получение результата использует прежний ID операции.
- Инструкции описывают поддерживаемые свойства, ограничения Auto Layout, стилей, переменных и компонентов. Предпросмотр свойств отделён от визуальной проверки макета.

## 0.7.18

- Ссылки `library.docs` из файлов проекта проверяются по точному списку HTTPS-доменов: `ui.shadcn.com`, `gravity-ui.com`, `developers.figma.com`.
- Запрещены учётные данные, произвольные порты и параметры запроса в таких ссылках. Перед чтением агент показывает URL и проверяет перенаправления; при невозможности такой проверки использует локальные материалы.
- Правила проекта и внешние документы явно обрабатываются как недоверенные данные. Для других библиотек сохраняется возможность использовать локальный профиль без сетевой ссылки.

## 0.7.17

- Безопасное обновление локального MCP и скилла: подготовка новой копии, резервное копирование, проверка сборок и откат при ошибке замены.
- Сохранение ключа подключения, настроек доступа к изображениям, логов и ID импортированного плагина при обновлении.
- Команда `install.mjs --check` проверяет соответствие установленного MCP, плагина и скилла. `--update` восстанавливает файлы даже при совпадении номера версии.
- Общий локальный сервер для нескольких клиентов, проверка совместимости версий и восстановление соединения без повторного выполнения завершённых изменений.
- Выбор дизайн-системы при первой настройке и отдельные правила проектов; профиль Gravity UI, переменные и синхронизация стайл-гайда.
- Аудит макетов, компонентов и токенов, диагностика соединения и отчёт без содержимого макета и ключей подключения.
- Воспроизводимые архивы, контрольные суммы и автоматическая проверка установки, обновления и сборки на macOS, Linux и Windows.

Работа с настоящей Figma Desktop проверена на macOS. Проверки Windows/Linux выполняются без графического приложения Figma; автоматическая регистрация через Windows `codex.cmd` остаётся отдельным ограничением. После обновления перезапустите MCP-клиент и плагин Figma.
